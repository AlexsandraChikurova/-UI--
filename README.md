# Focus Deck

Интерактивная панель продуктивности на чистом JavaScript. Учебный проект демонстрирует ООП, ES-модули, работу с DOM и внешними API.

## Возможности

- динамическое добавление, удаление, сворачивание и изменение порядка виджетов;
- независимые экземпляры списка задач;
- локальный виджет случайных фокус-цитат;
- интерактивный антистресс-виджет с авторским маскотом-мопсом;
- погода по городу через Open-Meteo API;
- конвертация валют через открытый Currency API;
- состояния загрузки, пустого ответа, ошибки и успешного результата;
- отмена устаревших сетевых запросов через `AbortController`;
- адаптивная сетка, управление с клавиатуры и видимый фокус.

## Архитектура

```text
index.html
main.js
js/
├── UIComponent.js     # абстрактная база, жизненный цикл и общие действия
├── Dashboard.js       # коллекция виджетов и управление панелью
├── ToDoWidget.js      # задачи
├── QuoteWidget.js     # случайные цитаты
├── PugWidget.js       # мопс-пауза и переключение состояний
├── WeatherWidget.js   # Open-Meteo API
└── CurrencyWidget.js  # Currency API
styles/
├── main.css           # каркас страницы и адаптивность
└── components.css     # компоненты и состояния виджетов
```

Каждый виджет наследуется от `UIComponent` и переопределяет `render()`. `Dashboard` работает с ними через единый интерфейс, не смешивая внутреннюю логику компонентов.

## Источники данных

- [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api) — поиск координат города.
- [Open-Meteo Forecast API](https://open-meteo.com/en/docs) — текущая погода.
- [Currency API](https://github.com/fawazahmed0/exchange-api) — открытые справочные курсы валют.

Оба сервиса работают без секретных API-ключей. Полученные данные выводятся через `textContent`, без вставки недоверенного HTML.

При каждом новом запросе предыдущий запрос конкретного API-виджета отменяется через `AbortController`, включая переход в пустое или локально рассчитанное состояние.

## Запуск

ES-модули требуют HTTP-сервер. Из папки проекта можно запустить любой статический сервер, например:

```bash
python -m http.server 4173
```

Затем откройте `http://127.0.0.1:4173/`. Для публикации выполните `node scripts/build.mjs`: готовые статические файлы появятся в `dist/`.

Открытие `index.html` через `file://` не рекомендуется.

## Ограничения

- курсы валют справочные и не являются банковской офертой;
- список задач хранится только до перезагрузки страницы;
- доступность API зависит от интернет-соединения.

## Журнал применения ИИ

ИИ использовался для первичного проектирования архитектуры, генерации базовой реализации классов, проверки требований задания и идей визуальной системы. Код был собран как единый проект, проверен по структуре, доступности и жизненному циклу компонентов. Перед защитой рекомендуется самостоятельно пройтись по каждому классу и уметь объяснить наследование, полиморфизм, `AbortController`, обработчики событий и безопасный вывод API-данных.
