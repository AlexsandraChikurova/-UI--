# Отправка задания

Скопируйте строку ниже и замените значения в угловых скобках:

```text
<Фамилия Имя Отчество> — сайт: <публичная ссылка>, репозиторий: <ссылка на GitHub>
```

## Перед отправкой

- открыть опубликованную ссылку в приватном окне браузера;
- проверить загрузку погоды и курсов валют;
- добавить, свернуть, переместить и удалить виджет;
- добавить, отметить выполненной и удалить задачу;
- убедиться, что репозиторий виден преподавателю;
- проверить, что в репозитории есть `README.md` с архитектурой и инструкцией запуска.

## Короткое объяснение для защиты

- `UIComponent` задаёт общий жизненный цикл и интерфейс виджетов;
- конкретные виджеты наследуются от него и переопределяют `render()`;
- `Dashboard` хранит коллекцию компонентов и вызывает единые методы — это полиморфизм;
- каждый виджет хранит собственное состояние и обработчики — это инкапсуляция;
- `destroy()` отменяет запросы, снимает обработчики и удаляет DOM-элемент;
- `AbortController` отменяет устаревший API-запрос перед новым;
- данные API вставляются через `textContent`, поэтому ответ сервера не исполняется как HTML.
